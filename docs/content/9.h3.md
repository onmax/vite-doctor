The `vite-doctor/h3` Rule Pack checks code written against H3, the HTTP framework under Nitro and Nuxt: request validation, method and client IP utilities, HTTP error handling, and the APIs H3 v2 removed or replaced. It activates in Nitro and Nuxt projects, and its diagnostics use the `H3` Diagnostic Code Prefix.

```bash
pnpm vite-doctor . --rules h3/request/prefer-validated-body
```
