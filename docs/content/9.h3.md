The `vite-doctor/h3` Rule Pack checks code written against H3, the HTTP framework under Nitro and Nuxt: request validation, method and client IP utilities, HTTP error handling, and the APIs H3 v2 removed or replaced. Its diagnostics use the `H3` Diagnostic Code Prefix.

It activates wherever H3 runs: in a workspace package that declares `h3`, such as an H3 server on srvx, and in Nitro and Nuxt projects, which run H3 without declaring it. In Nitro and Nuxt server files, H3 utilities are auto-imported, so the rules read them as globals. Everywhere else, a file counts only when it has a value import from `h3` or `nitro/h3`, and a utility counts only when it resolves to that import: a local function named `getHeader` is not H3's. Version-gated rules, such as the H3 v2 migrations, read the H3 version each package resolves.

```bash
pnpm vite-doctor . --rules h3/request/prefer-validated-body
```
