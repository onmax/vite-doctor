---

The first npm alpha publishes `vite-doctor` only. Use it as the single smart command for Vite, Vue, Nuxt, and Nitro projects.

## Run a smart scan

Run Doctor from the project root:

```bash
pnpm dlx vite-doctor@alpha .
```

`vite-doctor` detects the project framework, loads the built-in Vite, Vue, and Nuxt rule packs, and applies the rules that match the project, detected Nuxt modules/packages, rule requirements, optional type analysis, presets, and explicit `--rules`.

## Run project scripts

Use the default command when you want Doctor to run the scripts already defined by a JavaScript project:

```bash
pnpm dlx vite-doctor@alpha
```

Read the [CLI guide](/cli) for package-manager detection, script selection, framework-aware scans, and automation examples.

## Add Nuxt-aware checks

`vite-doctor/nuxt` is the Nuxt module export path from the `vite-doctor` package. Add it when you want persistent Nuxt evidence, the `nuxt doctor` command, and the optional MCP endpoint:

```bash
pnpm dlx nuxt module add vite-doctor/nuxt
pnpm exec nuxt doctor
```

Read [Nuxt getting started](/nuxt/getting-started) for the CLI workflow and [Nuxt module](/nuxt/module) for manifest generation.

## Override detection

Auto-detection is the default. Use `--framework vue|nuxt|vite|nitro` only when a project has unusual dependencies or layout:

```bash
pnpm dlx vite-doctor@alpha . --framework nuxt
```

## Connect agents

Keep the human workflow CLI-first. For agents, use the existing read-only MCP endpoint exposed by the Nuxt module:

```ts
export default defineNuxtConfig({
  modules: ["vite-doctor/nuxt"],
});
```

Read the [Nuxt AI guide](/nuxt/ai) for the MCP tools and client setup.
