Use `vite-doctor` from the project root to run Vite, Vue, Nuxt, and Nitro diagnostics.

Install dependencies first. The CLI does not run package-manager install commands.

## Run a framework scan

```bash
pnpm dlx vite-doctor .
```

Useful options:

```bash
pnpm dlx vite-doctor . --changed
pnpm dlx vite-doctor . --max-warnings 0
pnpm dlx vite-doctor . --rules nuxt/fetch/no-raw-fetch-in-setup
pnpm dlx vite-doctor . --fix
```

## Configuration

Use `doctor.config.ts` when you want a standalone trusted Doctor config:

```ts [doctor.config.ts]
import { defineDoctorConfig } from "@vue-doctor/core";

export default defineDoctorConfig({
  rules: {
    "vite/define/no-secret-define": "error",
  },
});
```

When Doctor runs through a host integration, pass the same policy through the plugin surface:

```ts [vite.config.ts]
import { doctor } from "vite-doctor";

export default {
  plugins: [
    doctor({
      config: {
        include: ["src/**", "vite.config.ts"],
        rules: {
          "vite/define/no-secret-define": "error",
        },
      },
    }),
  ],
};
```

For Nitro-backed Vite apps, including Vue, React, or any other Vite frontend, use the same plugin:

```ts [vite.config.ts]
import { doctor } from "vite-doctor";

export default {
  plugins: [doctor()],
};
```

Set `framework: "nitro"` only when auto-detection needs an explicit override.

## Run in CI/CD

Add a `doctor` script to the project:

```bash
pnpm pkg set scripts.doctor="vite-doctor . --max-warnings 0"
```

This GitHub Actions example installs dependencies, then runs the package script:

```yaml
name: Checks

on:
  pull_request:
  push:
    branches: [main]

jobs:
  checks:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version-file: .node-version
      - run: corepack enable
      - run: pnpm install --frozen-lockfile
      - run: pnpm doctor
```

## Nuxt projects

Nuxt projects should use the module and Nuxt host command:

```bash
pnpm add -D vite-doctor
```

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    [
      "vite-doctor/nuxt",
      {
        config: {
          rules: {
            "nuxt/routing/prefer-nuxt-useroute": "error",
          },
        },
      },
    ],
  ],
});
```

```bash
pnpm nuxt doctor
```
