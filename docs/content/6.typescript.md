Vite Doctor activates its TypeScript rules automatically when the project contains a `tsconfig.json` or TypeScript source files. The recommended preset focuses on unsafe type claims and unvalidated runtime data.

## Install

Add Vite Doctor to any TypeScript project:

```bash
pnpm add -D vite-doctor
```

Run Doctor from the project root:

```bash
pnpm vite-doctor .
```

No framework option or TypeScript-specific configuration is required. JavaScript-only projects do not activate these rules.

## Use the strict preset

The strict preset adds opinionated checks for runtime narrowing, conditional object spreads, and undocumented type assertions:

```bash
pnpm vite-doctor . --extends auto,vite-doctor/typescript/strict
```

## Run one rule

Use a TypeScript rule ID without selecting a framework:

```bash
pnpm vite-doctor . --rules typescript/boundaries/no-unvalidated-deserialization
```

Doctor returns compact structured output automatically in recognized agent runtimes. Use `--format agent` for a fixed agent contract or `--format json` for the complete machine report.
