---
title: Installation
description: Add Vue Doctor to a Vue 3.5 project.
---

Run the Vue entry point from a Vue project root:

```bash
pnpm dlx vue-doctor
```

Use `scan` or `check` explicitly when you want command names in scripts:

```bash
pnpm dlx vue-doctor scan .
pnpm dlx vue-doctor check .
```

## Expected result

The scan prints a text report with file paths, rule ids, messages, and suggestions. It exits with code `1` when it finds blockers or errors, and code `0` otherwise.

## Useful options

| Option             | Use it to                           |
| ------------------ | ----------------------------------- |
| `--changed`        | Scan changed files only.            |
| `--fix`            | Apply safe fixes.                   |
| `--unsafe-fix`     | Apply fixes that may need review.   |
| `--severity error` | Report only errors and blockers.    |
| `--rules <id>`     | Run a specific rule or rule filter. |
| `--max-warnings 0` | Fail CI when any warning remains.   |

## Rule coverage

Vue Doctor focuses on high-signal framework mistakes: prop mutation, missing `.value`, async or impure computed getters, watchers registered after `await`, missing `v-for` keys, unsafe `v-html`, and browser APIs in SSR paths.
