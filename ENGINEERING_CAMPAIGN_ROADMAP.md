# Engineering Campaign Roadmap

This backlog is evidence-driven from the current source and test inventory. Each planned row is intended to become one independently reviewable PR with a failing reproduction or coverage gap, a minimal implementation or fixture, and fresh verification. An absent literal Rule ID in the test tree is only an inventory lead, not evidence of missing behavioral coverage. For those rows, trace imported rule objects and grouped fixtures first; propose a PR only after reproducing a specific uncovered boundary case. Rows marked completed are historical records and are excluded from the remaining backlog; row numbers remain stable. Recheck linked PR states and current source before starting any planned work.
