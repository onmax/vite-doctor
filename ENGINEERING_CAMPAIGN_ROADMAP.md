# Evidence-driven engineering campaign roadmap

This backlog is a review queue, not a claim that every row is a confirmed product defect. Every row names an existing source location and a concrete verification boundary.

- **REPRO** means an actual Doctor Run probe currently demonstrates the stated mismatch. The implementation PR must preserve the clean counterexample and add the probe as a regression test.
- **GATED** means the source path and an uncovered branch or contract are real, but the expected behavior still needs an explicit fixture, an ADR decision, or an upstream contract check. The first PR may be a test/documentation decision and must close the row without a production change when the current behavior is correct.
- Rows are intentionally split by one root cause or one contract, so each can be reviewed and reverted independently. The 35 rule probes were run through the shared Doctor Run testkit; their full fixtures and output are in `/tmp/doctor-campaign-rules-findings.md` and `/tmp/doctor-campaign-rule-probes.json`.

The cache confinement probe is a confirmed security bug and has a fix ready on `71fcade` (review commit `ddce6b2`); it remains listed until that change is published. Existing landed work is recorded after the queue and is not counted as a future PR.
